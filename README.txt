FRB / FROSTBORN — ALLIANCE COMMAND CENTER v0.2

Open index.html in a modern browser.

Project decisions:
- Languages: English, Polish, Arabic (with RTL layout for Arabic).
- Access model: mixed — public knowledge/event guides + intended private member workspace.
- Contributions: everyone may suggest content; R4/R5 approve official changes.

Prototype features:
- Frost-themed responsive dashboard and navigation.
- English, Polish and Arabic interface translations.
- Public Knowledge and Event Center sections.
- Alliance Space concept for internal plans and assignments.
- Community Suggestions form with local demo approval queue.
- Live UTC daily reset countdown.
- Search across guide cards.

Important limitations:
- This is a static front-end prototype, not a deployed website.
- Alliance Space is a visual/demo area only. There is no real login, member verification, role-based authorization, shared database or server-side approval workflow.
- Suggestions and approvals exist only in the current browser session and are not shared with other visitors.
- Before public launch, add authentication, persistent database, server-side permissions (member / contributor / R4-R5), moderation logs, and hosting.
- The Alliance Championship content is a compact initial draft based on the supplied guide. Foundry content is a placeholder pending the complete reference text.
